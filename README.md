# 👨‍🍳 ChefMaster Pro - Project 11 (Συνταγές Μαγειρικής)

**Ελληνικό Ανοικτό Πανεπιστήμιο (ΕΑΠ)** **Ομαδικό Προγραμματιστικό Project - Ακαδημαϊκό Έτος: 2025-2026**

Η εφαρμογή **ChefMaster Pro** είναι ένα ολοκληρωμένο, αντικειμενοστρεφές σύστημα (OOP) διαχείρισης συνταγών μαγειρικής, αναπτυγμένο σε Python. Παρέχει ένα σύγχρονο γραφικό περιβάλλον (GUI) μέσω της βιβλιοθήκης `CustomTkinter` και υποστηρίζεται από σχεσιακή βάση δεδομένων `SQLite3`.

## ⚙️ Απαιτήσεις Συστήματος

- **Python:** Έκδοση 3.8 ή νεότερη.
- **Λειτουργικό Σύστημα:** Windows.
