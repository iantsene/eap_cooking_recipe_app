# 🧑‍🍳 ChefMaster Pro

Μια πλήρης εφαρμογή διαχείρισης και εκτέλεσης συνταγών μαγειρικής με δυνατότητα αποθήκευσης υλικών, βημάτων, εικόνων και εξαγωγής σε PDF/Excel.

## ✨ Δυνατότητες

- 📝 Δημιουργία, επεξεργασία, διαγραφή συνταγών
- 🥕 Διαχείριση υλικών, κατηγοριών και μονάδων μέτρησης
- 👨‍🍳 Λειτουργία εκτέλεσης συνταγής (Cooking Mode) με χρονόμετρο
- 🖼️ Υποστήριξη εικόνων για κάθε συνταγή
- 📊 Αναζήτηση και προηγμένα φίλτρα
- 📤 Εξαγωγή σε Excel (CSV) και PDF
- 🌓 Υποστήριξη Dark/Light θέματος
- 🇬🇷 Πλήρης υποστήριξη ελληνικών χαρακτήρων

## 📋 Απαιτήσεις Συστήματος

- **Λειτουργικό Σύστημα:** Windows 10/11
- **RAM:** 4GB ελάχιστο
- **Αποθηκευτικός χώρος:** 200MB ελεύθερος χώρος

## 🚀 Εκτέλεση του Προγράμματος

### Μέθοδος 1: Εκτελέσιμο αρχείο (Συνιστάται)

1. Κατεβάστε το αρχείο `ChefMaster_Pro.exe` από το GitHub
2. Τοποθετήστε το σε έναν φάκελο της επιλογής σας (π.χ. `C:\ChefMaster`)
3. Κάντε διπλό κλικ στο `ChefMaster_Pro.exe` για να εκκινήσει η εφαρμογή

> **Σημείωση:** Η πρώτη εκτέλεση θα δημιουργήσει αυτόματα τη βάση δεδομένων και τους απαραίτητους φακέλους.

### Μέθοδος 2: Εκτέλεση από πηγαίο κώδικα

```bash
# 1. Εγκατάσταση Python 3.8+
# 2. Εγκατάσταση απαιτούμενων βιβλιοθηκών
pip install customtkinter pillow fpdf

# 3. Εκτέλεση
python main.py
